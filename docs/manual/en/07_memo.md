# Memos

## Save a response

Save a useful AI response as a memo and give it a descriptive title. Memo text is user content and is not automatically translated when you change the interface language.

## View and copy

Open recent memos to review or copy their contents. Check generated text before treating it as authoritative or forwarding it to others.

## Share a memo

Creating a sharing link makes the selected memo accessible to anyone with that link. Review the complete memo for private information before sharing, and revoke the link when it is no longer needed.
