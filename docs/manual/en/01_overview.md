# Chat-Core AI overview

## What Chat-Core AI does

Chat-Core AI combines chat, reusable tasks, saved memos, prompt sharing, and an in-page AI agent. You can use chat without signing in, but signing in is required to save data and use account features across devices.

## Main areas

- **Chat:** ask questions, attach supported files, and continue earlier conversations.
- **Tasks:** reuse structured prompt templates for common work.
- **Memos:** save useful AI responses and share selected memos by link.
- **Prompt sharing:** discover, like, publish, and reuse public prompts.
- **Settings:** manage your profile, language, appearance, email address, and security options.
- **AI agent:** ask how to use the current page or request supported page actions.

## Language behavior

Change the interface language in Settings. Chat-Core AI follows the language you explicitly request or the language of your message. When neither is clear, it uses your saved interface language. Your chats, memos, and community posts are kept in their original language and are not translated automatically.
