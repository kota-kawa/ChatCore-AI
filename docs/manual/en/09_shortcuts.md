# Keyboard shortcuts

## Common controls

Use Tab and Shift+Tab to move between interactive controls, Enter or Space to activate the focused control, and Escape to close supported dialogs. Exact shortcuts can vary by browser and operating system.

## Text entry

The message composer may use Enter to send and Shift+Enter for a new line. Check the visible hint near the composer when accessibility software or input-method settings change this behavior.
