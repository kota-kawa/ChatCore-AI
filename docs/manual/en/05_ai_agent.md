# AI agent

## Ask about the current page

Open the AI agent from the lower area of the page. It can explain available features, suggest steps, and prepare supported page actions using the current page context.

## Page actions

The agent may navigate, click, enter text, or scroll through supported controls. Review actions that send, delete, publish, overwrite, or change account information before confirming them.

## Limits

The agent only knows the page state provided to it and may not see controls on a destination page until navigation completes. It cannot bypass authentication, permissions, or browser security.
