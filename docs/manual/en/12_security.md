# Security and privacy

## Protect verification codes

Verification codes are temporary credentials. Do not send them to anyone or enter them on a site reached through an untrusted link.

## Protect sensitive information

Do not enter passwords, API keys, private keys, authentication cookies, or information you are not authorized to process. Review attachments and shared content before sending.

## Unexpected account email

If you receive an email-address-change or sign-in code that you did not request, ignore the code, review your account security, and remove unknown passkeys or sessions where those controls are available.
