# Tasks

## Use a task

Tasks are reusable prompt templates for work such as summarization, translation, email drafting, comparison, and meeting notes. Select a task, provide the requested input, and review the generated output before using it.

## Default and custom tasks

Default tasks are displayed in your selected language. Editing a copied task makes it your own content; Chat-Core AI does not automatically translate custom task text. You can create, reorder, edit, or delete your own tasks while signed in.

## Translation task

Specify the target language when possible. If you do not specify it, the task uses its documented default and the language context of your input.
