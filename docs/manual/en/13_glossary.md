# Glossary

## Task

A reusable prompt template containing instructions, response rules, and optional examples.

## Memo

A saved copy of an AI response with a title and optional sharing link.

## Prompt

Instructions or context sent to an AI model. A public prompt is community content shared through Prompt Sharing.

## Passkey

A phishing-resistant sign-in credential protected by your device or password manager.

## AI agent

The in-page assistant that explains product features and can prepare supported page actions.
