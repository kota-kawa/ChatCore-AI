# 0011: 変わる文脈を会話履歴の後ろに置き、プロンプトキャッシュを効かせる

## 状態

採用

## 背景

OpenAI・Anthropic・Groq のプロンプトキャッシュは、リクエストの先頭からの一致にしか効きません。以前の組み立てでは、秒まで変わる現在時刻が最初の system メッセージの途中にあり、判断ループのステップごとに変わる `TurnState` と、ターンごとに変わる参照元・過去の検索結果・検索の引用方針は、先頭の system 群の直後（会話履歴の前）に差し込んでいました。そのため、会話履歴と生成 UI の契約はステップごと・ターンごとに全額課金されていました。実測では、GPT-6 Luna と Claude Haiku 4.5 のキャッシュ命中はほぼ 0 でした。

- 読み取りツール（`get_evidence`・`read_web_page`）を根拠が届いてから追加していたため、ツール定義（プロンプトの先頭）がステップの途中で変わり、以降のキャッシュがすべて外れていました。
- Claude には `cache_control` を付けておらず、しかも全 system メッセージを 1 つの `system` にまとめていたため、変わる文脈が入った時点で会話全体が対象外でした。
- GPT-5.6 以降の OpenAI は、何も指定しないと「最新メッセージの末尾」だけを区切りにしてプロンプト全体を書き込み（入力の 1.25 倍で課金）、会話履歴の途中までは再利用できませんでした。

## 判断

- メッセージは「固定の指示（基本プロンプト、ルームごとの指示、生成 UI の契約）→ 会話履歴 → 変わる文脈 → 最新のユーザー発話」の順に並べます。変わる文脈とは、現在時刻（`build_runtime_context_message`）、`TurnState`、検索の引用方針、参照元の検索結果、過去の検索結果です。差し込みは `insert_before_latest_user_message` で行います。
- 判断ループの契約（通常と回答専用）も末尾側へ移し、変更前と同じ相対順（`TurnState` → 検索の引用方針（根拠があるターンだけ）→ 契約）のまとまりとして最新の発話の直前に置きます。契約は状態の更新方法を説明しているため、契約だけを先頭に残して状態から離したところ、GPT-OSS 120B が更新封筒 `turn_state_update` をツールとして呼び出し、空回答の回復も増えました（実測）。同じまとまりに戻すと、どちらも 0 件になりました。
- 根拠を増やせる検索系ツールがあるターンでは、読み取りツールを最初のステップから提示し、根拠が無いうちの呼び出しには `not_found` を返します。予算切れによる取り下げはこれまでどおりです。
- アダプタ（`services/llm.py`）が、先頭の基本プロンプトの末尾と会話履歴の末尾にプロバイダごとの区切りを付けます。Claude は先頭の system 群だけを `system` に渡し（基本プロンプトに `cache_control`）、それより後ろの system メッセージは次のユーザーターンへ畳みます。GPT-6 Luna は `prompt_cache_breakpoint` を付けます（Responses API では assistant 出力に置けないため、直前の入力側へ寄せます）。Groq は自動キャッシュなので何も付けません。
- OpenAI の `prompt_cache_key` は使いません。GPT-5.6 以降では利用者ごとにキャッシュを分ける機能で、振り分けの改善にはならず、全利用者で共有できる基本プロンプトを利用者の数だけ書き込むことになるためです。

## 影響

- 判断ループの 2 ステップ目以降と、同じルームの次のターンで、固定の指示と会話履歴がキャッシュから読まれます。キャッシュ読み出しは Luna・Claude で入力の 0.1 倍、Groq の GPT-OSS で 0.5 倍です。
- キャッシュ書き込みは Luna・Claude で入力の 1.25 倍です。料金の記録（`services/usage_pricing.py`）はこの割増を含めて数えます。
- Claude では、履歴より後ろの変わる文脈が system ではなくユーザーターンの一部として渡ります。
- 互いに説明し合う指示と状態（契約と `TurnState` など）は、同じまとまりの中に置いて離さないでください。
- 新しい文脈を差し込むときは、ターンやステップで変わるなら `insert_before_latest_user_message`、固定なら先頭側に置いてください。ツール一覧も、1 ターンの間はできるだけ変えないでください。
